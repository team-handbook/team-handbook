## 공통 규칙

- 문서 언어: 한국어
- 브랜치 전략은 GITHUB FLOW 방식이다. 
- 브랜치명은  EX) '/이슈번호-브랜치명'
- 각 브랜치 작업한 내용을 main에 직접 push 하지 않는다.
- GitHub 웹은 이슈, PR, 리뷰에만 쓰고 나머지는 모두 터미널에서 수행합니다.
- 명령을 실행할 때마다 `git status`와 `git lg` 명령으로 상태를 확인합니다.
- 막히면 먼저 `git status`가 알려주는 안내 문구를 읽습니다.
